# CampusMate — Student Life & Study Planner

## About the Project
CampusMate is a student-friendly web application designed to help students organize their academic activities in one place.

## Objectives
- Manage assignments and deadlines.
- Organize daily study tasks.
- Track completed and pending work.
- Monitor academic progress.

## Planned Features
- Student dashboard
- Add, edit, and delete tasks
- Assignment deadlines
- Task completion tracking
- Progress summary
